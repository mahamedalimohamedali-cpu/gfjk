# CLI Assistant

CLI Assistant is a professional Windows-based desktop application designed to automate the process of generating and publishing social media content. It leverages Google Gemini AI to transform raw project descriptions into engaging, formatted posts tailored for Facebook Groups.

## Key Features

*   **AI-Powered Content Refinement**: Utilizes the Google Gemini API to automatically rewrite and format technical descriptions into professional Arabic posts, complete with structured paragraphs and emojis.
*   **Direct Facebook Integration**: Streamlines the publishing workflow by posting content directly to specific Facebook Groups using the Graph API and secure access tokens.
*   **Automated Project Linking**: Includes built-in logic to programmatically append GitHub repository links and professional calls-to-action to generated captions.

## Technical Stack

*   **Language**: C#
*   **Framework**: .NET / Windows Forms (WinForms)
*   **Integrations**: Google Generative AI (Gemini) and Facebook Graph API v19.0
